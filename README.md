BOOKSTORE MANAGEMENT SYSTEM — SPRINT 1 DEMO
===========================================

HOW TO RUN

1. Double-click BookstoreApp.exe
2. Wait for the console window to say the server is running
3. Open your browser and go to:

   http://127.0.0.1:5000

4. Log in using one of the demo accounts below.
